# Flags

Edit all flag captions in the header above. Each key is the exact image filename.

- `name`: the label beneath the expanded flag.
- `achieved`: a quoted month such as `"2024-05"`, displayed as **May 2024**.
- Leave `achieved` blank to use the earliest linked published checkpoint month.
- Collected flags are sorted newest first; WIP flags display only their names.

Add an image to this folder and a matching entry above to customize a new flag.
Images without an entry use their filename as the name. Checkpoint links determine
whether a flag is earned. The body of this file is authoring guidance, not site content.
